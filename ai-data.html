Property facts, not PDFs.

This page loads the current, published Astate listings from Wix CMS and exposes their public fields as compact JSON. AI tools still need browsing/API access to retrieve it; publishing a feed does not automatically add records to any model's training data or guarantee all models will recommend them.

Public listing fields

Reference, offer/requirement, property type, city, locality, area, price or budget, land use and a short description.

02

Private by default

Contact name, WhatsApp and email stay in a private intake collection. Posts containing real-estate property facts publish immediately. Phone, email and URL patterns are redacted from public descriptions; direct public posts are still public and may be copied by crawlers.

03

AI access instructions

Read llms.txt for source description and access notes. Public listings are also visible in the human-readable directory.

For developers and AI agents

Wix public collection ID: propertyListings. Public OAuth client ID is provided in this site's script config. An API-capable agent can mint a Wix anonymous visitor token and query the Wix Data items endpoint using the documented public-read collection. Do not try to access the private propertyIntakes collection.

Only published property fields appear in this feed. Private intake records must never be queried by public agents. No sample or invented listings are included.
